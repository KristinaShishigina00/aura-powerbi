# Демонстрационные данные

[Главная](../README.md) · [Модель](../docs/data-model.md) · [Метрики](../docs/metrics.md)

Включены полные CSV из переданного набора Aura. Реальные персональные записи не использованы. Seed исходного генератора: `20261003`.

| CSV | Строк |
| --- | ---: |
| [Users.csv](Users.csv) | 8 000 |
| [Products.csv](Products.csv) | 120 |
| [Recommendations.csv](Recommendations.csv) | 60 000 |
| [Interactions.csv](Interactions.csv) | 127 535 |
| [Routine.csv](Routine.csv) | 10 638 |
| [Date.csv](Date.csv) | 273 |
| [FunnelStages.csv](FunnelStages.csv) | 6 |

Кодировка UTF-8 BOM. Даты — ISO 8601 в UTC. Пустое поле означает отсутствие значения. Регистрации: 1 января–31 августа 2026; граница наблюдения: 30 сентября; окно результата: 30 дней после регистрации.

Один item Recommendations — отдельный продукт в выдаче, а не пользователь и не вся генерация. У принятого item есть предшествующий просмотр. Повторные просмотры имеют новые interaction_id, но бинарный признак viewed остаётся равным 1. Routine сохраняет первое добавление пары пользователь × продукт.

Типы кожи и состояния основаны на словаре предметной области. Возраст, цены, бренды, вовлечённость, вероятности действий и исходы учебные. Популярность, score, цена и сегмент влияют на вероятность действий в генераторе, поэтому наблюдаемые связи не доказывают причинный эффект в реальном продукте.

SHA256 каждого CSV и других материалов записан в [манифесте](../docs/file-manifest.json). Проверить комплект: `python scripts/validate_package.py` из корня репозитория.
