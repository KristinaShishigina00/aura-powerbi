# Источники комплекта

Пользователь указал архив Aura-Business-Analysis.zip, раздел 07_PowerBI. Рядом находилась распакованная папка с более поздней русской версией, готовым PBIX и скриншотами Desktop. Для комплекта использована эта обновлённая версия.

PBIX, CSV и скриншоты сохранены без изменений. Исходники PBIP упакованы без локальных .pbi-кэшей и настроек. Из model.bim извлечены 24 меры DAX. Браузерный HTML сохранён с добавленными ссылками на PDF, репозиторий и опциональный Power BI Service. В README и документах заново оформлены описание, определения метрик и аналитические выводы.

Численные выводы опираются на исходные CSV и сверены при подготовке. Исходные материалы сообщали о предыдущей проверке Windows Desktop; новый запуск Desktop при упаковке не выполнялся. Наличие таких записей не подменяет проверку в текущем окружении.

PDF комплекта — новый портфолио-отчёт: краткий анализ и предоставленные скриншоты Desktop, а не экспорт действующего фильтрованного отчёта из Service.
